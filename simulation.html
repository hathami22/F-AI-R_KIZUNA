Simulation assumptions and real-world integration

This is a software demonstration with synthetic crops, weeds, and GPS. Generated plants have perfect detection and stable identities. The targeting inset is schematic. YOLO inference, laser optics, power, biological efficacy, and physical safety systems require separate hardware validation. Each plant is counted once. Grid density is unique weeds divided by surveyed area. Unsurveyed cells export a null density. Partial cells use only their surveyed fraction.

Speed target = min(1.2 m/s, processing capacity ÷ (look-ahead weeds/m² × 2 m swath)). Acceleration and braking are bounded, so actual speed can temporarily exceed the target. Processing capacity is an assumed planning value. Each virtual pulse marks one weed as treated. Targets within 0.15 m of a crop stem are skipped. A 1 m fore-aft reach limits targeting, and missed weeds are reported. Pulse counts represent assumed treatment success in this demonstration.

Rows connect through a four-second headland movement with acceleration and braking. Heading changes use a simplified kinematic model. GPS is an ideal local projection with no receiver noise. The default origin is an editable example near Tunis. All exported geometry is simulated WGS84 longitude/latitude.

For a real field, record timestamped GNSS position, heading, camera pose, image calibration, and detections. Project stem pixels onto the ground using calibration and depth or a ground-plane model. Associate detections across frames to count each weed once. Position accuracy must support the grid size. An MP4 alone may lack the required GPS and calibration.
